Networking

Computer networking connects devices so they can communicate and share information and resources.

Key areas

  • IP addresses identify devices on a network.
  • TCP/IP is a core suite of communication protocols.
  • Subnetting divides a network into smaller networks.
  • Routers connect different networks; switches connect devices within a LAN.
  • Packet Tracer can be used to practise network configuration.

Practical example

Example: a router can connect a school local network to the internet.
