System Administration

System administration involves installing, configuring, maintaining and securing computer systems and servers.

Key areas

  • Windows Server provides services for organisations.
  • DNS translates domain names into IP addresses.
  • DHCP automatically assigns network configuration to clients.
  • Virtualisation allows multiple virtual machines to run on one physical computer.
  • User and permission management helps protect system resources.

Practical example

Example: an administrator can configure DHCP so computers receive IP settings automatically.
